A LITTLE HELP GETTING STARTED

From here to your home screen.

01 Android apps

Choose an Android APK download. Open the downloaded file and follow Android’s installation prompts. If asked, allow your browser to install apps, then return to the file.

EchoRemote and EchoDeck also need their matching Windows host on the computer you want to control.

02 Windows companion hosts

Download the Windows portable ZIP and extract the entire folder. For EchoDeck, open Start-EchoDeck.cmd. For EchoRemote, open Start-EchoRemote.cmd. Keep the host running while connecting from your tablet.

Close the older EchoRemote host before starting EchoDeck. The EchoDeck host also supports EchoRemote. Follow the included setup guide for pairing with your HTTPS Tailscale address and access key.

03 EchoAI & this store

Open EchoAI, then use its install option or your browser’s Install app / Add to Home Screen menu. On iPhone, open Safari → Share → Add to Home Screen.

You can install EchoStore the same way. Its interface is cached for offline browsing; downloading apps and opening EchoAI need a connection.
